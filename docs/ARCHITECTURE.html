P-FM NEWS 설계도

포스코 그룹·이차전지 뉴스를 60초 주기로 수집해 요약·SWOT 분석하고, 웹 포토카드와 텔레그램 채널로 내보내는 파이프라인. 프런트엔드·백엔드·DB 구성과 기사가 거쳐 가는 게이트, 그리고 무엇을 얼마나 보관하는지를 정리했다.

기준 2026-09-03 저장소 SQLite 8.7 MB 노출 기사 478건 코드 backend/main.py 1개 파일

01 — 구성무엇이 어디서 돌고 있나

파이썬 파일 backend/main.py 하나(약 5,200줄)가 API 서버·수집 루프· 텔레그램 봇을 모두 담고 있다. 프런트엔드는 프레임워크 없는 바닐라 JS 3파일이고, 데이터는 로컬 SQLite 파일 하나에 들어간다.

프런트엔드

파일줄역할
index.html227뼈대 마크업, 마스터 패널 모달
app.js941전체 로직 — 프레임워크·빌드 없음
style.css424딥네이비 테마, 3열 포토카드 그리드

상태는 state 객체 하나(필터·검색·페이지)에 모으고 URL 쿼리스트링과 동기화한다. 브라우저 저장소는 localStorage만 쓴다 — 즐겨찾기 목록, 마스터 토큰, 필터 접힘 상태. 서버로는 가지 않는다.

백엔드 — 16개 섹션

설정 → 저장소 계층 → 시드 → URL 정규화 → HTTP → 수집 → 본문추출 → 분류·중요도 → LLM → 중복판정 → 파이프라인 → 시세 → 텔레그램 → API → CLI 순으로 배치돼 있다. 저장소는 Storage 추상 클래스 아래 SqliteStorage와 SupabaseStorage 두 구현이 있어, .env의 DB_BACKEND 한 줄로 전환된다.

02 — 수집기사가 통과해야 하는 7개 게이트

게이트는 싼 판정을 앞에, 비싼 판정을 뒤에 두도록 순서가 정해져 있다. G0–G2.5는 네트워크를 쓰지 않아 비용이 0이고, HTTP 요청은 G3부터, 과금은 G6에서만 발생한다. 아래 숫자는 실제 1회 실행 로그다.

중복 판정 4단계

같은 사건을 여러 매체가 전재하므로 4단계로 묶는다. 앞 단계에서 확정되면 뒤로 안 넘긴다 — 임베딩(4단계)은 비용이 요약 단계를 넘어설 수 있어 1회 실행당 30회로 막아 두었다.

단계판정임계비용
1정규화 URL 완전 일치—DB 조회
2본문 SHA-256 해시 일치—DB 조회
3제목 유사도 AND 발행시각 24시간 이내0.90로컬 계산
4제목 임베딩 코사인 유사도0.92OpenAI 과금

3단계에서 유사도가 0.62–0.90 사이인 "잔여 후보"만 4단계로 보낸다. 중복으로 판정되면 새 URL을 별칭으로 누적하고, 새 기사의 언론사 등급이 더 높으면 카드의 표시 정보(제목·링크·언론사·기자·썸네일)를 그쪽으로 승격한다. 요약·SWOT 등 분석 결과는 같은 사건이므로 그대로 두고, 피드가 재정렬되지 않도록 발행시각도 유지한다.

03 — 관련성포스코가 안 나와도 남기는 세 갈래

기본 규칙은 "제목·스니펫·본문 어디에도 포스코·계열사가 없으면 버린다"이다. 그런데 정부 정책·해외 통상 조치·배터리 생태계 뉴스는 회사명이 안 나와도 대외협력·소재사업에 직결된다. 그래서 세 갈래의 예외를 뒀다.

04 — 알림텔레그램으로 나가는 조건

저장과 발송은 다른 판정이다. 웹에는 다 올라가지만, 텔레그램 채널로는 아래 조건을 전부 통과한 기사만 나간다.

마스터 패널에서 조절되는 값

설정기본값동작
관련도 임계값500–100 슬라이더. 권장 하한 40을 표시하되 자유롭게 지정
항상 발송 키워드비어 있음본문에 있으면 중요도·야간 게이트를 우회

글로벌 통상환경 알림꺼짐위와 같은 2단 필터

05 — 데이터무엇을 얼마나 보관하나

기사 본문은 분석이 끝나면 즉시 지운다. 저작권과 최소 보관 원칙 때문이다. 현재 article_bodies에 3행만 남아 있는 건 분석 대기 중인 기사가 그만큼이라는 뜻이다.

일회성 정리 명령

규칙을 바꿨을 때 기존 데이터에 소급 적용하는 CLI가 준비돼 있다. fixcategories(재태깅) · fixgroups(그룹사 보강) · fixpress(언론사명) · fixofftopic(무관 기사 보관) · reanalyze(끊긴 분석 복구) · reswot(SWOT 재생성) · fixlinks · fixdates.

부트스트랩 억제. 첫 실행 시각을 기록해 두고, 그 이전에 발행된 기사는 절대 알림하지 않는다. 파이프라인이 오래 멈췄다 재개될 때 과거 기사가 한꺼번에 발송되는 것을 막는다.
