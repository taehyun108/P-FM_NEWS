# frontend

포토카드 뉴스 아카이브 화면. **backend API만 호출한다.**

## 담당 범위 (PRD 대응)

| 파일 | 역할 | PRD |
|---|---|---|
| `index.html` | 헤더 · 시세 티커 · 통계 바 · 필터 · 카드 그리드 · 푸터 | F6.1, F9.3 |
| `style.css` | 딥네이비(`#16337A`) 브랜딩, 반응형 3/2/1열 | F6.1, F6.3 |
| `app.js` | 다중 선택 필터, 카드 렌더링, 칩 중복 제거, SWOT 툴팁 | F6.1a, F6.2a, F6.2b |

## 원칙

1. **API 키를 이 폴더의 어떤 파일에도 두지 않는다.** Supabase service role key, OpenAI 키, 텔레그램 토큰 모두 backend 전용이다.
2. 외부 시세 API를 브라우저에서 직접 호출하지 않는다 (F9.2).
3. 필터는 그룹 내 OR / 그룹 간 AND, 재클릭 해제, URL 쿼리스트링 동기화 (F6.1a).
4. 칩은 렌더링 직전 정규화 키로 중복 제거한다 (F6.2b).

> 코드는 PLAN.md 검증 통과 후 작성한다. 현재는 구조만 잡힌 상태다.
